# Intro to Markdown

Here are some markdown basics to reference while you make this dictionary.

## Visualize
To see the markdown at any time, press
```
Ctrl + Shift + V
```

## Headings
```
# Big heading
## Medium heading
### Small heading
and so on
```

## Bold and Italics
```markdown
**This text is bold**
*This text is italicized*
```

## Lists
### Bullet Lists:
```
- item
- item
    - sub-item
```
### Numbered Lists:
```
1. first
2. second
```

## Code Blocks
### Inline code:
To get the length of x, use `len(x)`

### Multi-line code block:
```python
print('hello')
```
